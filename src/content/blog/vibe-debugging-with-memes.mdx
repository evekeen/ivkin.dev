### MCP Servers

We can integrate the meme generator right into the place where you do your work these days, which is the agenting system for coding.
The most popular one is obviously Cursor, so let's start with it.

Ideally you would just paste the error message into the agentic chat and get a meme in response while the agent is trying to analyze and fix the error in background.

### The Setup

#### Step 1. Get Your OpenAI API Key
1. Visit OpenAI Platform and create an account: https://platform.openai.com
2. Navigate to `Settings -> API Keys`
3. Click "Create new secret key" and copy the generated API key. Save it securely - we will use it later. You won't be able to see the key again if you close the page.

#### Step 2. Register on ImgFlip
1. Go to ImgFlip Signup and register for a free account: https://imgflip.com/signup
2. Complete the sign-up process and log in.
3. Your ImgFlip username is shown on your profile; your password is the one you set during registration. Keep both handy.

Reset ImgFlip password for Google accounts:  

1.	If you signed with Google, to get your password you will need to reset it in the profile.
2.	Go to Settings: https://imgflip.com/settings
3. Click "Change password"
4. Enter anything in the current password field
5. Enter your new password in the new password field
6. Click "Change password"

#### Step 3. Clone the Repository and Build the Project

Open your terminal and run the following commands:

```
git clone https://github.com/sundai-club/error-meme
cd error-meme
npm install
npm run build
```

#### Step 4. Set Up Global MCP Configuration

Create a global MCP configuration file in your home directory at ~/.cursor/mcp.json. Paste the following configuration, replacing placeholders with your credentials and the correct path to your build:

```
{
  "mcpServers": {    
    "meme": {
      "command": "node",
      "args": [
        "/path/to/error-meme/build/index.js"
      ],
      "env": {
        "OPENAI_API_KEY": "openai-api-key",
        "IMGFLIP_USERNAME": "imgflip-username",
        "IMGFLIP_PASSWORD": "imgflip-password"
      }
    }
  }
}
```

Restart your Cursor IDE to load the new configuration.

### See it in action

Let's start the Cursor IDE and open the chat.

#### Check the MCP server status

First let's check if MCP server is working:
1. Open the Cursor Settings (click the gear icon on the top-right corner)
2. Go to the MCP tab
3. You should see the "meme" server listed there

![](/images/mcp-tab.png)

The **meme** server should have a green dot next to it, indicating that it is active.
The server should list this tool: `generate_error_meme`.

Everytime you change something in the code, you need to restart the server. Make sure to click the  "Refresh" button on the **meme** server card.

#### Get some memes

Now let's open the chat.
Make sure the chat is in the **Agent** mode.
Insert an error message there. For example, something like this:
