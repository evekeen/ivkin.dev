# ivkin.dev

Modern personal landing page and blog built with Astro and TailwindCSS.

## Tech Stack

- **Astro 5.0** - Modern static site generator
- **TailwindCSS 3** - Utility-first CSS framework
- **TypeScript** - Type-safe development
- **MDX** - Markdown with JSX components

## Features

- ⚡ Lightning-fast performance with zero JavaScript by default
- 🎨 Modern, minimalist design
- 🌓 Dark mode support
- 📱 Fully responsive
- 📝 13 blog posts migrated from Hugo
- 🔍 SEO optimized
- 📡 RSS feed
- 🗺️ Sitemap generation

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The site is deployed to GitHub Pages from the `docs/` directory. Push to the main branch to trigger deployment.
